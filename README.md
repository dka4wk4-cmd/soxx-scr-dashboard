# SOXX SCR 대시보드

SOXX · SOXL · SOXS — VIX + SCR 트윈 전략을 아이폰 화면에 맞춘 단일 HTML 대시보드입니다.
`index.html` 하나로 동작하며(GitHub Pages), 파일을 내려받아 열어도 그대로 렌더링됩니다.

## 보는 법

- **상단** — SOXX 최근 종가, 전일 대비 등락, 시간축별 신호등 배지(일봉·주봉·숏차트 주봉·VIX 버프), 마지막 업데이트 시각.
- **일봉 / 주봉 탭** — Stoch(5,3,3) %K·%D, CCI(14), RSI(14) 값과 과매도(20 / -100 / 30)·과매수(80 / +100 / 70) 게이지.
- **차트** — 캔들 + 5·10·20·50 이평선(주봉은 5·20주선) + 볼린저밴드(20,2). 손가락으로 짚으면 그 봉의 시·고·저·종가와 지표값이 나옵니다. 범례를 눌러 선을 켜고 끌 수 있습니다.
- **지지 · 저항 · VIX** — 20개월선, 50개월선, 50일선 이격도, 200일선, 볼린저밴드, VIX 주봉 5·10주선(숏/롱 버프), VIX 월봉 배열.
- **롱 / 숏 체크리스트** — 전략 요약의 조건별 충족 여부(O/X)와 충족 개수.
- **새로고침 버튼** — Yahoo Finance에서 다시 받아 지표를 재계산합니다. 브라우저에서 직접 요청이 막히면 내장 데이터를 그대로 유지하고 안내 문구를 띄웁니다.

## 데이터

- 내장 데이터: Yahoo Finance `SOXX` 일봉 2년 · 주봉 2년 · 월봉 10년, `^VIX` 주봉 6개월 · 월봉 10년.
- Yahoo가 주봉·월봉 응답 끝에 같은 기간 봉을 중복으로 붙여 주는 경우가 있어, 같은 주/월에 속한 마지막 봉은 제거하고 계산합니다.
